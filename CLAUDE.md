# FinDeependence UI — use for every page, app, report and artifact

All UI built for this project (web app, claude.ai artifacts, PDF/Excel exports) uses the
FinDeependence brand from the "FinDeependence Studio" artifact
(https://claude.ai/artifact/6m26Vv2ykoS6irWvrR2ocm).

- **Header:** navy band `#0E2740` with the round FinDeependence logo (`assets/logo_circle.png`
  in the Studio artifact) on a white circle with a teal ring; a small mono label "FinDeependence"
  in `#7FD3D6`; byline "CA Deep Dalal · Chartered Accountant · Fund Manager".
- **Colours (light):** bg `#F6F2E8`, surface `#FFFFFF`, ink `#14273D`, muted `#5D6B7A`,
  line `#E2DACA`, chip `#EAE3D2`, navy `#0E2740`, green `#3C9A08` (primary buttons and active tab),
  teal `#2C8F93`, pen blue `#1D5FA8`.
- **Colours (dark):** bg `#0B1B2C`, surface `#122840`, ink `#EEF3F7`, muted `#9FB0C2`,
  line `#23405F`, navy `#06121F`, green `#5FC22A`, teal `#7FD3D6`, pen `#8DB8F0`, chip `#1B3553`.
- **Type:** Bricolage Grotesque 800 for headings, Inter for body text, JetBrains Mono 700 uppercase
  with wide letter-spacing for labels, table headers and pills; mono for numbers.
- **Shapes:** panels 14px radius with 1px line border; pills 5px radius, mono, uppercase.
- **PDF exports:** navy top strip with "FINDEEPENDENCE" + byline, navy table headers,
  chip-coloured total rows, "FinDeependence" in the footer.
- In this app, sHNI uses teal and bHNI uses pen blue.
